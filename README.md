# commit-roast 🔥

Roast, grade, and rewrite your git commit messages with swappable AI personas — Linus Torvalds, a passive-aggressive PM, Shakespeare, your high-school English teacher.

**Status:** early WIP — see [PLAN.md](./PLAN.md) for the full plan and roadmap.

```bash
$ commit-roast --persona linus --count 3
abc1234  "fix stuff"
  Grade: F
  Linus: "This is exactly the kind of garbage commit message that makes me want to..."
  Suggested: fix(parser): handle empty input without panicking
```
